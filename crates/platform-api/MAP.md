# MAP: `crates/platform-api`

Платформонезависимые трейты и контракты взаимодействия с ОС (системный трей, окна, глобальные хоткеи, захват экрана, системные метрики, аудио/USB-транспорт). Не содержит `unsafe` и WinAPI-зависимостей.
