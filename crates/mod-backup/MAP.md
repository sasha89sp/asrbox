# MAP: `crates/mod-backup`

Модуль портативного резервного копирования (`BK-001..BK-004`): архивация только настроек или программы целиком + настроек в стандартный `.zip` (метод STORE + CRC-32 на чистом `std`, без внешних крейтов и без `unsafe`). Лимит: <= 100 строк.

## Файлы

| Путь | Назначение |
| --- | --- |
| `src/zip.rs` | Чистый Rust-генератор стандартных `.zip`-архивов (STORE + IEEE CRC-32 + UTF-8 имена). |
| `src/lib.rs` | Конфиг `backup.cfg`, режимы `SettingsOnly` / `FullAppAndSettings`, создание и поиск бэкапов в `data/backups/`. |
