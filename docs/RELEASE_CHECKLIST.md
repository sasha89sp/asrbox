# RELEASE_CHECKLIST.md — Чеклист выпуска релиза `asrbox`

Применяется перед публикацией каждого релиза портативной сборки `asrbox` для Windows 10/11 (x64).

## 1. Проверка CI (GitHub Actions, `windows-latest`)

- [ ] `cargo fmt --check` — успешно.
- [ ] `cargo clippy --workspace -- -D warnings` — 0 предупреждений, без `unwrap()`/`expect()`, `unsafe` только в `crates/platform-windows`.
- [ ] `cargo xtask atlas-check` — `ATLAS.md` и все `MAP.md` актуальны.
- [ ] `cargo test --workspace` — все тесты пройдены.
- [ ] `cargo build --release` + проверка размера `asrbox.exe` < 25 МБ (`NF-005`).
- [ ] Смоук-тест `asrbox.exe --selftest` завершился с кодом 0.
- [ ] При наличии внешних зависимостей актуализирован `docs/LICENSES.md` (и пройден `cargo deny check`).

## 2. Проверка бюджетов `NF-001..NF-010` и защитных механизмов (`SPEC.md`)

- [ ] **NF-001**: CPU в покое < 1%.
- [ ] **NF-002**: RAM в покое (без Whisper) < 30 МБ.
- [ ] **NF-003**: Запуск до готовности трея < 1 сек.
- [ ] **NF-004**: Обработка события хука клавиатуры < 1 мс.
- [ ] **NF-005**: Размер `asrbox-vX.Y.Z.exe` < 25 МБ.
- [ ] **NF-006 / NF-008**: Падение любого модуля не роняет программу; супервизор перезапускает модуль (<= 3 сек на первый рестарт; политика 1/5/30 сек, отключение после 3 падений подряд).
- [ ] **NF-007**: Выключенный модуль не загружается (0% CPU, 0 МБ RAM).
- [ ] **NF-009**: Версия совпадает в `Cargo.toml`, имени файла, `--version`, трее, «О программе» и заголовке логов; дочерний процесс с чужой версией не запускается.
- [ ] **NF-010**: Логи (`off/error/info/debug/trace`, ротация 5x2 МБ в `data/logs/`) и профилирование (`tracing::instrument`) переключаются на лету; онлайн-монитор и ZIP-пакет диагностики работают корректно.
- [ ] Проверены один экземпляр (mutex), `--safe-mode` (и зажатый `Shift`), аварийное отключение `mod-keyboard`, сворачивание по кнопке `X` в трей, бэкапы настроек и отсутствие секретов в `data/`.

## 3. Документация и публикация тега

- [ ] Обновлена `workspace.package.version` в корневом `Cargo.toml`.
- [ ] Обновлены `CHANGELOG.md`, `HANDOFF.yaml`, `BUGS.md` (закрытые перенесены в `docs/archive/bugs-closed.md`).
- [ ] Проверены лимиты строк: `HANDOFF.yaml` <= 80, `ATLAS.md` <= 150, каждый `MAP.md` <= 100.
- [ ] Создан тег `vX.Y.Z`, запущен `.github/workflows/release.yml`, проверены `asrbox-vX.Y.Z.exe` и `.sha256` в GitHub Releases.
