# RELEASE_CHECKLIST.md — Чеклист выпуска релиза `asrbox`

Применяется перед публикацией каждого релиза портативной сборки `asrbox` для Windows 10/11 (x64).

## 1. Проверка CI (GitHub Actions, `windows-latest`)

- [ ] `cargo fmt --check` — успешно без расхождений.
- [ ] `cargo clippy --workspace -- -D warnings` — 0 предупреждений, подтверждено отсутствие `unwrap()` / `expect()` и отсутствие `unsafe` вне `crates/platform-windows`.
- [ ] `cargo run -p xtask -- atlas-check` — все крейты из `crates/` и `xtask` присутствуют в `ATLAS.md`, все `.rs`-файлы присутствуют в `MAP.md`.
- [ ] `cargo test --workspace` — все модульные и интеграционные тесты пройдены.
- [ ] `cargo build --release` — релизный бинарник `target/release/asrbox.exe` собран успешно.

## 2. Проверка нефункциональных бюджетов (`SPEC.md`, NF-001..NF-010)

- [ ] **NF-001 (Портативность)**: запуск `asrbox.exe` из пустого каталога создаёт только `./data/`, без скрытых записей в `%APPDATA%` и системный реестр.
- [ ] **NF-002 (Холодный старт)**: время запуска до готовности трея <= 500 мс.
- [ ] **NF-003 (Память в простое)**: Working Set в трее <= 40 МБ.
- [ ] **NF-004 (CPU в простое)**: средняя нагрузка CPU в простое <= 0.5%.
- [ ] **NF-005 (Размер бинарника)**: `asrbox.exe` <= 15 МБ, отсутствуют внешние несистемные DLL-зависимости.
- [ ] **NF-006 (Надёжность)**: проверены граничные сценарии ошибок; каждый `unsafe`-блок в `platform-windows` имеет актуальный комментарий `// SAFETY:`.
- [ ] **NF-007 (Логирование вкл/выкл)**: переключение логов работает на лету; при выключенных логах файлы в `data/logs/` не пишутся; секреты маскируются; ротация <= 20 МБ.
- [ ] **NF-008 (Профилирование функций)**: включение/выключение профилировщика работает без перезапуска, накладные расходы при выключении < 1%.
- [ ] **NF-009 (Онлайн-монитор нагрузки)**: `mod-monitor` корректно отображает CPU/RAM/потоки/профилировщик и приостанавливает опрос при скрытии окна в трей.
- [ ] **NF-010 (Трей по кнопке `X`)**: нажатие `X` сворачивает окно в системный трей без остановки фоновых модулей; выход через меню трея освобождает ресурсы и завершает процесс <= 2000 мс.
