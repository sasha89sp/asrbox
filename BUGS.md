# BUGS.md — Реестр дефектов и ограничений `asrbox`

## Правила ведения

Каждая запись дефекта должна содержать:
- **ID**: `BUG-NNN`
- **Статус**: `open` | `in-progress` | `fixed` | `wontfix`
- **Серьёзность**: `critical` | `high` | `medium` | `low`
- **Версия обнаружения** и **Крейт**
- **Описание и шаги воспроизведения**
- **Причина и исправление** (заполняется при закрытии)

## Известные ограничения среды

### ENV-001: Отсутствие локальной компиляции Windows-таргета
- **Статус**: Постоянное ограничение рабочего процесса
- **Описание**: Исходный код редактируется в среде без Windows 10/11 и без локального Windows-раннера.
- **Митигация**: Все проверки (`cargo fmt --check`, `cargo clippy --workspace -- -D warnings`, `cargo run -p xtask -- atlas-check`, `cargo test --workspace`, `cargo build --release`) выполняются в GitHub Actions на `windows-latest` (`.github/workflows/ci.yml`).
