# SPEC.md

## 0. Специфика проекта
Название:       asrbox
Что это:        портативная модульная программа для Windows 10/11 (x64)
Среда:          Google AI Studio Build + GitHub Actions (`windows-latest`)
Стек:           Rust, Slint (`1.18`, `winit` + `renderer-software`), `window-vibrancy`, `windows-rs`, `whisper.cpp`, WebDAV
Портативность:  один `.exe`, данные в папке `data/` рядом с ним, без установщика
Приоритеты:     1) минимум CPU/RAM, 2) отсутствие лагов, 3) надёжность хуков и отладки
Поведение окна: кнопка закрытия (X) сворачивает программу в трей; выход только через меню трея
Ограничения:    ИИ не запускает Windows-код; хуки и UI проверяются вручную на Windows
Не делаем:      установщик, веб-движок (Electron/WebView), облака кроме WebDAV

## 1. Бюджеты ресурсов и системные требования
- **NF-001**: CPU в покое: меньше 1% (0.0% для окон Slint — реактивная отрисовка только по событию).
- **NF-002**: RAM в покое (без Whisper и при закрытых окнах Настроек/Заметок): меньше 30 МБ; открытые окна Slint запускаются отдельными on-demand процессами (`--ui-settings`, `--ui-notes`) и полностью освобождают память после закрытия.
- **NF-003**: Запуск до готовности трея: меньше 1 сек.
- **NF-004**: Обработка события хука клавиатуры: меньше 1 мс.
- **NF-005**: Размер portable `.exe`: меньше 25 МБ.
- **NF-006**: Падение любого модуля не закрывает программу и другие модули.
- **NF-007**: Выключенный модуль: 0% CPU и 0 МБ RAM (не загружается).
- **NF-008**: Перезапуск упавшего модуля: не дольше 3 сек (базовая задержка первого рестарта 1 сек; политика 1 / 5 / 30 сек, отключение после 3 падений подряд).
- **NF-009**: Единая версия (`workspace.package.version`) в имени релизного файла (`asrbox-vX.Y.Z.exe`), `--version`, окне «О программе», подсказке трея, свойствах `.exe` и заголовке каждого лога.
- **NF-010**: Вкл/выкл логирования (глобально и помодульно, уровни `off / error / info / debug / trace`, ротация 5 файлов по 2 МБ в `data/logs/`) и профилирования функций (`tracing::instrument`) на лету без перезапуска + онлайн-монитор нагрузки (`mod-monitor`) и сбор ZIP-пакета диагностики из трея.

## 2. Защита при работе, настройки и безопасность
- **Один экземпляр**: повторный запуск проверяет именованный mutex и показывает уже запущенную копию.
- **Безопасный режим**: запуск с `--safe-mode` (или зажатым `Shift`) поднимает только трей без модулей.
- **Аварийное отключение клавиш**: жёстко заданная, не переназначаемая комбинация мгновенно отключает `mod-keyboard`.
- **Кнопка закрытия (`X`)**: сворачивает окно `asrbox` в трей; полный выход — только через меню трея. (Если потребуется перехват кнопки закрытия сторонних окон вроде Chrome — оформляется отдельно в `specs/window-rules.md` до реализации.)
- **Резервные копии настроек**: бэкап перед миграцией формата и перед применением настроек из WebDAV; поля `settings_version` и `written_by` не позволяют старой версии перезаписать настройки новой.
- **Секреты и модели**: пароли WebDAV и токены хранятся только в Windows Credential Manager (никогда в репозитории или синхронизируемых файлах). Модель Whisper скачивается при первом включении с проверкой SHA-256.
- **Изоляция процессов**: единый `asrbox.exe` выступает супервизором и запускает дочерние модули с `--module <имя>`; дочерний процесс с несовпадающей версией не запускается.
