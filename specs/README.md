# specs/ — Детальные спецификации модулей `asrbox`

В этом каталоге хранятся спецификации поведения отдельных модулей (`specs/<модуль>.md`) и их критерии приёмки.

## Соглашение об идентификаторах

- `KB-001..` — `specs/mod-keyboard.md` (переназначение клавиш, аварийный хоткей)
- `DK-001..` — `specs/mod-dock.md` (неограниченное число док-панелей в стиле macOS)
- `SP-001..` — `specs/mod-speech.md` (Whisper, ленивая загрузка + SHA-256)
- `WD-001..` — `specs/mod-webdav.md` (WebDAV, синхронизация папок, бэкапы)
- `MN-001..` — `specs/mod-monitor.md` (онлайн-монитор CPU/RAM/событий/функций)
- `SC-001..` — `specs/mod-screenshot.md` (процесс захвата по запросу)
- `HW-001..` — `specs/mod-huawei.md` (модем Huawei, AT-команды)
- `WG-001..` — `specs/mod-widgets.md` (модуль виджетов рабочего стола; первый виджет — Google Календарь `.ics`)
- `DB-001..` — `specs/mod-debug.md` (отладочный модуль: живые логи, TRACE, запись в файл, метрики CPU/RAM/GDI, отчёт)
- `AB-001..` — `specs/mod-about.md` (модуль «О программе»: версия, портативность, текущие пути, история версий)
- `WR-001..` — `specs/window-rules.md` (опционально: правила для сторонних окон, например перехват `X` у браузера Chrome, если потребуется)
